# Pwn Pipeline

A automated pipeline for setting up and analyzing CTF pwn challenges. Extracts files, analyzes binaries, and generates exploit templates.

## Quick Start

```bash
# Process latest download
./pwn-pipeline --name buffer_overflow

# Organize by CTF and use debug mode
./pwn-pipeline --name heap_exploit --ctf picoCTF2024 --debug
```

## Features

- **Organization**: Categorizes files (binaries, libraries, sources) into `~/Desktop/Ctf`.
- **Analysis**: Generates `analysis.md` with checksec, symbols, and vulnerability checks.
- **Templates**: Creates `exploit.py`, `.gdbinit`, `solve.sh` and Obsidian writeups.

## Commands

| Script | Purpose | Example |
|--------|---------|---------|
| `pwn-pipeline` | **Main Orchestrator**. Runs full pipeline. | `./pwn-pipeline --name chall --debug` |
| `setup.py` | Extracts and categorizes files. | `./setup.py --name chall --archive ch.zip` |
| `analyze.sh` | Analyzes a directory of binaries. | `./analyze.sh /path/to/chall` |
| `templates.py` | Generates exploit & writeup templates. | `./templates.py --name chall --challenge-dir .` |

## Configuration

Paths can be configured via environment variables.

| Variable | Default (Normal) | Default (Debug `--debug`) |
|----------|-------------------|---------------------------|
| `PWN_DOWNLOADS` | `~/Downloads/ctf` | `PWN_TEST_DOWNLOADS` (default: `/tmp/pwnflow/downloads`) |
| `PWN_DEST` | `~/Desktop/Ctf` | `PWN_TEST_DEST` (default: `/tmp/pwnflow/ctf`) |
| `PWN_VAULT` | `~/Desktop/Vault/Ctf` | `PWN_TEST_VAULT` (default: `/tmp/pwnflow/vault`) |

Use `--debug` to run in test mode without affecting your real files.
